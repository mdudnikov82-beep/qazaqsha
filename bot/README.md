# Telegram-бот Qazaqsha

Бот превращает список слов в ссылку для импорта в приложение.

**Пользователь пишет:**

```
кітап — книга
қалам — ручка
```

**Бот отвечает** списком слов, кнопкой «📥 Добавить в Qazaqsha» (открывает
веб-версию с готовым импортом) и кодом, который можно вставить в
Android-приложении (Словарь → ➕).

Бот **ничего не хранит**: сообщение разбирается, ответ отправляется, данные
забываются. В лог пишется только количество ответов, без самих слов.

## Запуск

Нужен Python 3.10+, сторонние библиотеки не нужны.

1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.
2. Скопируйте `.env.example` в `.env` и вставьте токен.
3. Запустите:

   ```bash
   python bot/qazaqsha_bot.py
   ```

Бот работает, пока запущен процесс, — для круглосуточной работы его нужно
запустить на сервере (VPS, Raspberry Pi и т. п.), например как службу
systemd.

## Тесты

```bash
cd bot && python -m unittest -v
```

Формат кода и правила разбора совпадают с приложением
(`lib/features/custom_words/word_import.dart`); общий тестовый пример есть в
тестах обеих сторон.
