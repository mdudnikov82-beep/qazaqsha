# Qazaqsha

Приложение для изучения казахского языка для русскоговорящих. Тропа
уроков с экзаменами, 200 правил грамматики с упражнениями, квизы со словами
и предложениями, свои наборы слов, интервальное повторение и мягкая
геймификация.

*A Kazakh learning app for Russian speakers: topic lessons, word and sentence
quizzes, spaced repetition and gamification.*

**Бесплатно и навсегда:** без подписок, без платных функций и без рекламы.
Весь курс открыт всем.

**▶ Открыть в браузере: https://mdudnikov82-beep.github.io/qazaqsha/**

На телефоне откройте ссылку и выберите «Добавить на главный экран» —
приложение появится с иконкой, как обычное. Прогресс хранится в браузере
на вашем устройстве.

**📱 Android:** скачайте APK со страницы
[Releases](https://github.com/mdudnikov82-beep/qazaqsha/releases/latest).

**🤖 Свои слова:** пришлите их боту [@Kei9jkBot](https://t.me/Kei9jkBot) —
он ответит ссылкой для импорта.

## Возможности

- **Словарь на 1505 слов** в 46 темах — от приветствий и семьи до покупок,
  путешествий, техники и традиций. Поиск на обоих языках (без учёта регистра
  и разницы «е/ё»), список А–Я по казахскому или русскому алфавиту,
  избранное, карточка слова с примером предложения.
- **Карточки** по теме или избранному: «знаю / не знаю», незнакомые слова
  уходят в повторение.
- **144 примера предложений** для заданий «Соберите предложение».
- **Тропа уроков:** около 300 уроков по 5 слов, каждый — своя ступенька.
  Курс разделён на 7 разделов; в конце каждого — **экзамен** (15 заданий,
  нужно 80%), и только после него открывается следующий раздел.
- **200 правил грамматики** во вкладке «Правила»: 100 о глаголах, 50 о
  существительных (падежи, притяжательные окончания…), 50 о других частях
  речи. В каждом — объяснение, таблица форм, примеры и 4 упражнения;
  проверка по каждой теме.
- **Свои слова:** несколько наборов, добавление вручную с подсказками из
  словаря, вставка списком «сөз — слово» (порядок языков неважен) с
  правкой перед добавлением, ссылка от Telegram-бота. Набором можно
  поделиться ссылкой; у каждого — карточки и тренировка.
- **Пять видов заданий:**
  - карточка нового слова;
  - выбор перевода (русский → казахский и обратно);
  - ввод слова с панелью казахских букв **ә ғ қ ң ө ұ ү һ і**;
  - поиск пар;
  - сборка предложения из слов.
- **Ошибки** возвращаются в конце урока. Ответ «журек» вместо «жүрек» засчитывается
  как «почти» — с подсказкой про казахские буквы.
- **Интервальное повторение** (система Лейтнера): слово возвращается через
  1, 3, 7, 16 и 35 дней; ошибка — и оно повторяется сразу. Прогноз на
  неделю, ступени памяти, режимы «Сложные», «Избранное», «Случайные».
- **Геймификация без стресса:** очки опыта и уровни, цель дня и недели,
  серия дней подряд с заморозками (зарабатываются каждые 7 дней) и
  возможностью вернуть серию после одного пропуска, 9 достижений. После
  перерыва приложение встречает, а не ругает: рекорд и прогресс остаются.
- **Статистика на главной:** выучено слов, время занятий, ошибок всего,
  пройдено уроков.
- **Профиль:** имя, звание по уровню, календарь активности, лучшая серия,
  прогресс достижений, напоминание о занятиях (Android), резервная копия
  прогресса кодом и сброс.
- **Светлая и тёмная темы** в цветах флага Казахстана с казахским орнаментом;
  режим «Авто» следует настройке телефона. Анимации отключаются, если в
  телефоне включено «Уменьшить движение».

## Запуск

Нужен [Flutter](https://docs.flutter.dev/get-started/install) 3.47 или новее.

```bash
git clone https://github.com/mdudnikov82-beep/qazaqsha.git
cd qazaqsha
flutter pub get

flutter run -d chrome     # в браузере
flutter run               # на подключённом Android-телефоне
```

Для сборки под Android нужны Android SDK и NDK 28.2 — Gradle подскажет,
чего не хватает.

## Тесты

```bash
flutter test
```

Тесты покрывают правила игры (уровни, серию дней, интервальное повторение,
проверку ответов), генератор квизов, работу с базой данных, а также проходят
урок целиком через интерфейс — с правильными ответами и с ошибкой.

После изменения таблиц базы данных перегенерируйте код:

```bash
dart run build_runner build
```

## Структура проекта

```
lib/
├─ app/            тема (светлая и тёмная палитры), навигация
├─ core/           общие виджеты, казахские буквы
├─ data/
│  ├─ database/    таблицы, миграции, загрузка словаря
│  └─ repositories/ словарь, прогресс, статистика, уроки, свои слова
└─ features/
   ├─ home/        главная: цель дня, «продолжить», статистика, слово дня
   ├─ lessons/     лестница уроков, разделы и экзамены
   ├─ quiz/        генератор заданий, урок, экзамен, повторение, проверка
   ├─ dictionary/  словарь, поиск, А–Я, карточка слова, карточки
   ├─ custom_words/ свои слова: импорт по ссылке, коду или списку
   ├─ review/      интервальное повторение и его режимы
   ├─ grammar/     правила грамматики и упражнения
   ├─ profile/     уровень, календарь, достижения, настройки, копия
   └─ gamification/ правила XP, уровней, серии дней; достижения
assets/data/
├─ dictionary.json  1505 слов: [русский, казахский, пояснение]
├─ sentences.json   144 предложения: [тема, русский, казахский]
└─ grammar.json     200 правил: объяснение, формы, примеры, упражнения
bot/                Telegram-бот: список слов → ссылка импорта (Python)
```

## Словарь

Слова и предложения лежат в `assets/data/` в простом JSON и легко
дополняются. Переводы составлены вручную; если вы нашли ошибку — откройте
issue или пришлите pull request.
